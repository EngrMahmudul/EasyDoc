EasyDoc

A complete PDF toolkit that runs entirely in your browser using pdf-lib, PDF.js, Tesseract OCR and SheetJS. Your documents are processed on your own device and are never sent to a server — close the tab and they're gone.

Good to know

Office conversions, OCR, summarising and translation use the best available in-browser equivalents and are labelled in each tool. Every tool and option is free with no size, page, file-count or daily-use limit — a very large file may simply take longer and use more memory on a low-memory device, and it is processed in chunks, page by page, with progress.

Install

Tap Install app above (or “Add to Home Screen” in your browser menu) to use EasyDoc like a native app, including offline.

🪟 EasyDoc on Windows 10 / 11

Install EasyDoc as a desktop app: in Edge use the “App available” icon in the address bar or … → Apps → Install EasyDoc; in Chrome use the install icon or ⋮ → Save and share → Install page as app. It then opens in its own standalone window, pins to Start / taskbar, and works offline. Drag files straight from Windows Explorer onto any tool, use Ctrl+O for the classic file picker, and right-click the taskbar icon for quick access. Files of any size are processed in place on your PC — there is no MB limit; a very large file may just take longer on a low-memory machine.

Developer note: EasyDoc is a standards-based PWA with no server dependencies — the same index.html + assets/ can be wrapped unchanged with Tauri or Electron (load the local index.html, grant file-drop + dialog permissions) to ship a signed Windows .exe installer later. Runtime detection: window.EasyDocDesktop is set when a desktop shell injects it; the web build sets data-runtime="pwa" on <html>.
